# NVivo Handoff for Focus-Group Analysis

Use NVivo to preserve and query the analytic design, not to replace it.

## Prepare the Data

- keep a stable group ID and speaker ID;
- format transcripts so speaker names can be recognized consistently;
- retain question, activity, and time or paragraph markers;
- store group-level attributes separately from participant-level attributes;
- import field notes, debriefs, chat logs, and artifacts with source-type labels;
- document any transcript cleaning or translation.

## Recommended Structure

| NVivo object | Use |
|---|---|
| File or source | One group transcript, debrief, or artifact |
| File classification | Group mode, date, category, site, moderator, and setting |
| Case | Participant, subgroup, or group when analytically required |
| Case classification | Participant role or attributes permitted by consent |
| Code | Substantive, interactional, contextual, and question-linked concepts |
| Memo | Group summary, analytic decisions, theme or finding development |
| Relationship or link | Explicit analytic relation when it adds value |

## Useful Queries

- matrix coding: theme or code x group category;
- coding query: intersections of substantive and interaction codes;
- text search: trace a participant term, followed by contextual reading;
- crosstab: descriptive overview of cases or file classifications;
- coding comparison: only when the analytic approach genuinely uses multiple-coder comparison;

Always inspect source context after a query. Query counts are navigation aids, not findings.
