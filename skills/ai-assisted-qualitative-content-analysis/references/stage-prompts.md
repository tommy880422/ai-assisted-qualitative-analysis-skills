# 各階段可直接複製的指令

【 】內換成自己的研究內容。每一則都寫明工具該做什麼、不能替研究者決定什麼。可以貼給任何對話式 AI 工具使用。

每一則會讀到研究資料的指令，貼出去之前先確認兩件事：這個工具可以讀哪一種版本的資料（對照倫理審查的核准內容）；附件是不是那個版本。雲端的 AI 服務原則上只給去識別化的版本，去識別化由研究者自己或用本機程式先做好，不要請雲端 AI 代做。

## 階段 0　錄音轉錄與逐字稿整理

### 整合兩個來源的逐字稿

```text
附件是同一場訪談的兩份逐字稿（版本：【去識別化版本／原稿，原稿須在核准範圍內】），分別由【轉錄工具甲】和【轉錄工具乙】產生。
請逐段比對，整合成一份逐字稿：
1. 兩份一致的地方直接採用。
2. 兩份不一致的地方，不要自行決定，把兩種寫法並列，標上【待確認】與時間點，我會回去聽錄音。
3. 說話者無法確定時標【說話者待確認】，不要猜。
4. 轉錄規則是【研究者定的規則，例如保留語氣詞、重複與停頓】。不要潤飾，不要補上錄音裡沒有的字。
最後列出所有待確認之處的清單。
```

### 統一逐字稿格式

```text
這是【N】場訪談的逐字稿，格式不一致。請先告訴我哪一份最適合當標準格式與理由。
我同意後，把其中一份改成標準版給我看（另存新檔，原檔不動，每段加行號），我確認模板後再處理其他場。
只改格式，不改任何一個字的內容。
```

## 階段 1　初步閱讀、備忘、個案摘要

### 個案摘要

```text
附件是【N】場訪談的逐字稿。在套用任何理論或類別之前，請先為每個個案寫一份簡短的摘要。
本研究的個案是【整場團體／個別受訪者】。
每份摘要包含：這個個案談了哪些與研究問題有關的內容、特別值得注意的段落（附行號）、與其他個案明顯不同之處。
只描述逐字稿裡有的內容，不要詮釋、不要歸類、不要評價。
【有會後的書面補充或補訪時：另列一節，註明來源。】
你自己的觀察另列在最後，標明不是摘要的一部分。
```

### 閱讀提示單

```text
請依【第 N 場】的逐字稿與個案摘要，整理一份閱讀提示單，給我對照逐字稿閱讀、寫備忘用。
這份不是備忘；備忘是我自己的想法，你不要替我寫。
分節如下，每一節先列描述性的筆記（附行號），再提出讓我思考的問題，最後留「你的回應：」空著：
〇 讀之前（我對這一組的預期、訪談當時的情形）
一 訪談的情境
二 值得注意的段落（列表：行號、誰、內容）
三 意思不清楚、要回頭確認的地方（特別是主持人說出連結、受訪者只回答「對」的地方）
四 受訪者的用詞
五 同一個人前後的說法
六 團體的互動
七 主持人的提問
八 和別人不太一樣的人
九 讀完之後（最意外的事、對類別的提示、要在其他個案對照的事）
十 我在場才知道的事
筆記只寫逐字稿上看得到的內容，不要加入你的解讀。
```

### 陪研究者閱讀並記下回應

```text
我現在對照逐字稿讀【第 N 場】，會用打字回應提示單的每一節。請你：
1. 把我的話照原樣填進提示單對應的「你的回應」，標上日期。不要改寫，不要補內容；我沒回應的記為未回應。
2. 我要找某段話時，回逐字稿找出來，連主持人的提問一起貼給我，並指出哪些是受訪者自己說的、哪些是主持人說而受訪者只回答「對」。
3. 我說的和逐字稿對不上時，列出行號與原文讓我決定，不要默默照寫，也不要自己改。
4. 你發現自己先前整理的摘要或提示單有錯時，告訴我，我同意後再更正，並留下更正日期與原先的寫法。
```

### 把回應整理成備忘

```text
請把我在【第 N 場】提示單的回應整理成備忘。
每一則標明：日期、行號、類型（描述／詮釋／與後續分析有關的安排）。
每一則分成兩欄：
「研究者說的」放我的原話，只改明顯的錯字，改了哪些列在最後；
「AI 整理的」只放對應的行號與逐字稿上看得到的事實，不要加你的解讀。
某一句如果是你提出、我採用的，照實註明。
最後列出：我沒有回應的項目、要我確認的地方、這份備忘是怎麼做出來的（步驟與用到的工具）。
我確認之後才算定稿。
```

## 階段 2　發展主類別並試用

### 由理論文獻草擬主類別

```text
我的研究以【理論名稱與主要文獻】為分析視角，分析方法是 Kuckartz 與 Rädiker 的結構式質性內容分析。
請只依附件的理論文獻草擬主類別，不要讀逐字稿。每個類別寫出：定義、何時編、何時不編、與相近類別的區辨、依據的原文（照錄原句並附頁碼）。例句先留空，不要自己造句。
哪些是原文的用語、哪些是把理論轉成分析方法時的延伸，分開標明。
```

可以把這一則分別交給兩三個工具，各自獨立起草，再請其中一個合成，並把各份草稿不同的地方列出來交研究者決定。合成時，引用的原句要回全文核對。

### 檢查主類別合不合用

```text
附件是全部個案的備忘、訪談大綱與主類別草稿。請整理三件事，每一點附備忘的編號或逐字稿行號：
(1) 這些類別能不能涵蓋我在備忘裡認為重要的內容，逐項對照；
(2) 有沒有反覆出現、卻沒有類別可放的內容；
(3) 理論類別和訪談大綱的主題可以怎麼搭配，列出兩到三種做法，各自的依據與後果。
由我決定，不要替我選。
```

### 改成第一輪版本

```text
請依我的決定把編碼手冊改成第一輪版本，另存新檔，舊版保留：
只留主類別；原先想到的次類別移到附錄，標為「候選名稱，階段 4 參考」。
片段範圍的規則寫在最前面：片段切粗，針對同一個提問的整段回答編成一個片段；同一段可以編到多個主類別。
版本紀錄寫明這次改了什麼、依據、誰草擬、誰決定。
```

### 試用

```text
請用第一輪版本的手冊試編【指定的段落，約占全部資料的 10–25%，要涵蓋不同組別與不同性質的內容，並包含沒有用來修訂手冊的段落】。
每筆附行號、依據原句與理由。規則不夠清楚、你沒有把握的地方列成問題，附前後文，一題一題問我。
```

要比較幾個工具時，把同一則指令、同一段資料（去識別化版本）分別交給各工具，彼此看不到對方的結果。比較的單位與算法事先寫明，例如以受訪者的每一行發言為單位，算各工具標的類別完全相同的比例。結果照實記錄；它用來找出不清楚的規則，不是信度。

## 階段 3　第一輪編碼

### 用主類別逐場編碼

```text
請依編碼手冊【第一輪版本的版次】編碼【第 N 場】，只用主類別。
從頭到尾依序編。與主類別無關的段落不編。
片段切粗：針對同一個提問的整段回答編成一個片段；談同一個主題的整段話即使跨好幾段也編成一段。片段要帶上理解它所必需的提問，離開上下文仍要看得懂。同一段可以編到多個主類別。
每筆要有：片段行號、依據原句（必須是片段內的原文）、主類別、判斷理由。
手冊沒有涵蓋的情形不要硬編，標為待決並說明。
出現手冊沒有的新內容時，不要自行新增類別，請提出建議，附原文與行號，並說明是新的概念還是既有類別的變化，由我決定。
編完一場先給我看，我確認後才編下一場。
```

### 新增類別或修改定義之後

```text
手冊已改為【版本】，修改內容是【新增的類別或改動的定義】。
請回到已編完的【第 N 至 N 場】的逐字稿重讀，包括當時沒有編碼的段落：
(1) 找出符合新類別或新定義、但當時沒有編的內容，列為建議補編，附行號與原句；
(2) 找出已編的列中受這次修改影響的，逐筆提出建議，列出原值、建議的新值與理由。
這些都是建議，我確認後才改。不受影響的列不要動。最後告訴我重讀了幾場、建議補編幾筆、建議修改幾筆。
```

## 階段 4　歸納次類別

一個主類別做一次。先做研究最核心的主類別。

```text
請把全部個案中編到主類別【名稱】的片段全部列出來（附編碼 ID、個案、行號）。
然後依這些片段提出次類別：
1. 先逐段讀，列出未排序的初步清單，每一項附支持它的編碼 ID；
2. 整理清單、找出面向，意思相近的合併，必要時再歸成較高的一層；
3. 為每個次類別寫定義、何時編、何時不編，並從資料裡挑典型的引文當例句（附行號）；
4. 留一個「其他」。
附錄的候選名稱只當參考：資料裡沒有的不要硬放，資料裡有而候選名稱沒有的要加。
次類別要在幾個個案中都出現，只屬於單一個案的另外列出。
列出你拿不定的地方與兩種以上的分法，由我決定。
```

## 階段 5　第二輪編碼

```text
主類別【名稱】的次類別已定案（手冊【版本】）。請把全部個案中編到這個主類別的片段，逐筆分到次類別。
每筆附依據原句與理由。同一個片段含兩個次類別的內容時，可以再切成較小的片段，並註明。
放不進任何次類別的先編「其他」，另外列出來並說明內容，由我決定要不要新增次類別。
編完一場先給我看。
```

### 個案的主題摘要（選做）

```text
請依第二輪編碼的結果，為每個個案在【選定的主類別】各寫一段摘要，整理成個案與類別的矩陣。
摘要只根據編到該格的片段，附編碼 ID，不要加入片段以外的內容。
```

## 編碼的檢視（用在階段 2 的試用、階段 3、階段 5）

### 以第二個人工智慧工具檢視編碼（盲判）

```text
你在做 AI 輔助檢視。下面是編碼手冊中【類別】的定義與規則，以及訪談片段（已代號化）。
你看不到原編碼者在這個類別的代碼。請依手冊獨立判斷每個片段的【類別】，並寫出依據的原句與理由。
只依手冊判斷，不要加入手冊沒有的類別。
```

這一則只檢查已選出的片段編得對不對。有提供其他代碼當脈絡時，在紀錄裡寫明提供了哪些。

### 檢查漏編與片段範圍

```text
附件是【第 N 場】的完整逐字稿（已代號化）與編碼手冊。下面是這一場已編碼片段的行號範圍，不含代碼：【行號清單】。
請讀【指定的段落，例如行 1–300】，列出：
(1) 依手冊應該編碼、但不在行號清單裡的內容，附行號、原句與你認為適用的類別；
(2) 清單中的片段，有沒有切掉理解它所必需的提問或前後文。
只列出來並說明理由，不要改任何東西。
```

### 複核不一致之處

```text
請比對原編碼與檢視結果。不一致的列逐筆回到手冊與原文複核，每一列給我一個建議：
建議修改、建議維持，或依手冊無法判定（附原文與兩種判法）。每列寫下依據的手冊條文與理由。
不要直接改編碼表。我確認後才修改；每筆修改留下原值、新值、理由、日期與決定者。
另請從一致的列中隨機抽【N】列給我重看。
若同一個類別有很多不一致，請指出是定義的哪一句造成的，我會考慮修訂手冊。
```

## 階段 6　分析

### 類別是否已經穩定

```text
請依手冊的版本紀錄與編碼表整理兩張表：
(1) 每個類別與次類別是在哪一版手冊、看哪幾場資料時形成的；
(2) 每個類別與次類別在各場第一次出現的位置。
另外指出手冊定稿之後才新增的類別各是什麼、屬於新的概念還是既有概念的變化，以及哪些分組的資料比較少。
這兩張表只能說明類別在現有資料中是否穩定。資料是否飽和、能宣稱到什麼程度由我判斷，請只提供數字與依據。
```

### 歸納與檢驗研究結果的類別

```text
請把編了【要歸納的類別，寫明是手冊裡的哪一個】的列依【個案或組別】彙整，提出歸納的方案，每一類附全部支持的編碼 ID。
方案提出後，回到個案摘要、備忘、其他類別的列與逐字稿中沒有編碼的段落，找不符合這個方案的情形與其他說得通的解釋，附行號。
另列出哪些列放不進任何一類。分類由我比較後定案。
```

## 階段 7　撰寫、記錄與揭露

### 草擬研究結果

```text
請依【歸類表】與編碼草擬【章節】的段落。每個論點要對得到編碼 ID，候選引文附行號並逐字照錄。
只寫資料支持的內容；詮釋的部分標明是你的建議，由我決定是否採用與如何修改。
```

### 核對研究結果與資料

```text
請逐筆核對這一章的每個數字與每段引文：數字要對得到編碼表，引文要與逐字稿原文逐字相符並註明行號。
對不上的列出來，不要自行修改正文。
```

### 整理 AI 使用的揭露

```text
請依各階段的過程紀錄、手冊的版本紀錄與修改紀錄，整理 AI 使用的說明：每個階段哪個工具做了什麼、讀的是哪一種版本的資料、我確認了什麼、哪些沒有重看。
只寫紀錄裡查得到的；紀錄裡沒有的列為待我補充，不要推測。還沒做的階段不要寫成已經完成。
```
