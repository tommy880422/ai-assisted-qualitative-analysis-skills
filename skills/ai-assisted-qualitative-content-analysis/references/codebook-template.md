# 編碼手冊與紀錄的格式

這些欄位是為了讓每一筆編碼都能回到原文、每一次修改都能回到決定。研究者可以增減欄位，但「依據原句」「判定狀態」「修改紀錄」三項建議保留。

## 一、類別系統

手冊分兩個版本，依序建立，不要一開始就寫成第二個版本。

- **第一輪版本（階段 2 定稿，階段 3 使用）：** 只有主類別與描述標記。起草時想到的次類別放在附錄，標為「候選名稱」，不用來編碼。
- **第二輪版本（階段 4 定稿，階段 5 使用）：** 在選定的主類別底下加入由資料歸納的次類別。

| 類別組 | 來源 | 說明 |
|---|---|---|
| 主類別 | 研究問題與訪談大綱，或由理論文獻演繹 | 每個類別註明來源；出自理論的，註明是哪一份文獻的哪個概念，並附原句與頁碼 |
| 次類別 | 歸納（由編到該主類別的全部片段） | 階段 4 才建立。註明屬於哪一個主類別、是看哪些片段形成的 |
| 描述標記 | 分析需要 | 例如發言依據的是親身經驗、假設情境或一般看法；受訪者是自己說出來的，還是只確認主持人的話。資料是焦點團體時，記下這段話回應誰，以及是附和、反對、補充還是改口 |

與書上用語的對應如下，寫方法章時用書上的用語。

| 本範本 | 書上的用語 | 依據 |
|---|---|---|
| 主類別 | 主類別（main category）。出自理論的，類型上是理論類別（theoretical category）；出自訪談主題的，是主題類別（thematic category） | 3.1 節（pp. 51–59）；類別類型見 2.2 節（pp. 35–37）；第一輪類別系統的要求見 p. 104 |
| 次類別 | 次類別（sub-category），由資料歸納 | 3.2、3.3 節（pp. 59–76）；階段 4 的做法見 pp. 106–110 |
| 描述標記 | 不是書上的用語。依內容而定：記錄客觀情形的是事實類別（factual category）；依研究者的標準分等級的是評價類別（evaluative category）；屬於整個個案的特徵（年級、組別）記為個案的屬性，不逐段編碼（這一項是本範本的做法） | 類別類型見 2.2 節（pp. 35–37） |

書上不事先把全部文本切成固定的編碼單位再編碼，那是古典內容分析的做法；質性內容分析通常以意義單位為片段，片段可以重疊或互相包含，判斷邊界的標準是離開上下文仍看得懂（pp. 45–46）。但書上也要求在開始編碼前先想好片段的範圍（p. 67）。所以本範本不是省略編碼單位，而是把它寫成第三節的「片段範圍」規則，連同要帶上多少上下文一起寫。有兩種情形例外：事實類別與受訪者自己的用語（自然類別）可以只編很短的詞語（p. 46）；要計算校正機率的一致性係數時，才需要事先劃定單位（p. 87）。

## 二、每個類別要寫的內容

| 欄位 | 內容 |
|---|---|
| 代碼與名稱 | 例如 D3.2 擔心被認識的人看見 |
| 類別類型 | 理論、主題、評價、分析、事實、自然（受訪者自己的用語）等，依書上 2.2 節。類型不同，編碼時要求的判斷也不同 |
| 層級 | 主類別、次類別，或個案的屬性。第一輪版本只有主類別 |
| 定義 | 一到兩句 |
| 何時編 | 具體的判斷線索 |
| 何時不編／區辨 | 與相近類別的差別，改編哪一個 |
| 例句 | 取自資料，附編碼 ID |
| 形成來源 | 主類別：研究問題、訪談大綱或理論（文獻、原句、頁碼）。次類別：資料（看了哪些片段、在哪一版形成） |

## 三、判斷規則與邊界案例

- **片段範圍：** 寫在最前面。以完整的意思為單位；一個意思跨幾句或幾段就編成一段；理解發言所必需的提問一併納入；片段離開上下文仍要看得懂（Kuckartz 與 Rädiker，2023，p. 105）。同一段可以編到多個類別。第一輪片段切粗：針對同一個提問的整段回答可以編成一個片段，談同一個主題的整段話編成一段（p. 105）。
- **計數單位：** 寫明之後計數時算的是個案數還是片段數，焦點團體的個案是整場還是個人（p. 90）。比較組別通常算個案數；另外算片段數時寫明用途。
- **判斷規則：** 跨類別的通則，逐條編號。例如「依據原句必須在片段範圍內」「一般性看法須能連回本人處境才計為本人的情形」。
- **邊界案例決定：** 研究者對個別案例的裁決。欄位：編碼 ID、問題、選項、決定、理由、日期、是否改了定義。日後遇到同類情形比照辦理。裁決若改變了類別的適用範圍，同時改定義、升版，並檢查先前的場次有沒有同類情形。

## 四、編碼表（每場一張）

| 欄位 | 說明 |
|---|---|
| 編碼 ID | 場次加序號，例如 S1-C016。事後補編的列在前一列 ID 後加 a、b，不重排 |
| 逐字稿版本、手冊版本 | 這一列是依哪一版逐字稿的行號、哪一版手冊編的。重判後更新手冊版本 |
| 行號起、行號迄 | 對應上一欄的逐字稿版本 |
| 受訪者（代號）、組別 | 片段含多人發言時，列出全部代號，並註明這筆編碼算在誰身上 |
| 回應對象與互動（焦點團體） | 這段話回應誰；附和、反對、補充、改口 |
| 事件編號（理論以事件為單位時） | 同一人談到的不同事件分開編號 |
| 原文 | 片段全文 |
| 依據原句、依據行號 | 支持這筆編碼的原句，必須逐字取自片段 |
| 各類代碼 | 第一輪：主類別一欄（可複選）、描述標記。第二輪：加上次類別一欄 |
| 編碼輪次 | 第一輪或第二輪；第二輪的列註明出自哪一筆第一輪的片段 |
| 判定狀態 | 該類空白時填原因：不適用、資料不足、待決 |
| 分析備忘 | 判斷理由；修改時寫「日期、原值→新值、理由、誰決定」 |
| 初步編碼者 | 例如 AI 工具名稱 |
| 狀態 | 待研究者確認、已確認（附日期）。AI 輔助檢視後有修改的列，要再確認一次 |

## 五、版本紀錄

| 版本 | 日期 | 修改內容 | 依據 | 草擬者與決定者 |
|---|---|---|---|---|
| v0.1 | | 建立初版（主類別草稿） | 理論文獻、訪談大綱 | AI 草擬，待研究者審閱 |
| v0.2 | | 依試用結果修訂…… | 試用的段落（場次與行號）；研究者某日的決定 | 研究者決定，AI 修改 |
| v1.0 | | 第一輪版本：只留主類別，候選次類別移到附錄 | 全部個案的備忘；研究者的決定 | 研究者決定，AI 修改 |
| v2.0 | | 第二輪版本：在主類別【名稱】下加入次類別 | 該主類別的全部片段（筆數） | AI 提出，研究者決定 |

新增類別或改了定義的版本，在「修改內容」寫明重讀了哪幾場的逐字稿、補編幾筆、重判幾列。沒有重讀就寫沒有與原因。

最後一欄要寫清楚。日後寫揭露時，這一欄就是「誰做了什麼」的證據。

## 六、備忘（階段 1）

每個個案一份。每一則的欄位：

| 欄位 | 說明 |
|---|---|
| 編號 | 個案加序號，例如 M1-07 |
| 日期 | 研究者寫下這個想法的日期；之後修正的另記日期 |
| 範圍 | 行號，或整個個案 |
| 類型 | 描述、詮釋，或與後續分析有關的安排（Kuckartz 與 Rädiker，2023，p. 94） |
| 研究者說的 | 研究者的原話，只改明顯的錯字 |
| AI 整理的 | 對應的行號與逐字稿上看得到的事實；不放 AI 的解讀 |
| 修正經過 | 研究者核對逐字稿後改了什麼；某一句若由 AI 提出、研究者採用，照實註明 |

檔案最後另列：研究者沒有回應的項目、研究者的確認（日期與內容）、錯字更正的對照、這份備忘是怎麼做出來的。研究者回應的原始紀錄（閱讀提示單）另外保留，不覆蓋。

## 七、編碼檢視的修改紀錄

| 編碼 ID | 類別 | 原值 | 檢視工具的判斷（每個工具一欄） | AI 的複核建議（修改／維持／無法判定） | 理由 | 研究者的決定與日期 |
|---|---|---|---|---|---|---|

檢視工具用幾個、各自看得到哪些資料（有沒有提供其他代碼當脈絡），寫在表的最前面。研究者抽查「建議維持」與「工具答案相同」的列時，另記抽了幾列、改了幾列。漏編與片段範圍的檢查結果另列一張表：場次、行號、建議的類別或問題、研究者的決定。

另外保留一份檢視前的原始比對結果，不要覆蓋。報告方法時以檢視前的數字為準。

幾個工具各自編同一段再比較時，另記：比較的單位（例如受訪者的每一行發言）、算法、各工具的列數、完全相同的比例、看的是不是修訂手冊時用過的段落。這組數字照實保留，包括偏低的。
