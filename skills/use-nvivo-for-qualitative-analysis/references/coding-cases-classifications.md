# Codes, Cases, and Classifications

## Map Concepts to NVivo Objects

| Analytic need | NVivo structure |
|---|---|
| Store a transcript, image, audio, video, note, or dataset | File/source |
| Represent a participant, organization, site, group, event, or another analytic unit | Case |
| Store case metadata such as role, age band, site, or cohort | Case classification and attributes |
| Store source metadata such as mode, date, language, or document type | File classification and attributes |
| Represent analytic meaning | Code |
| Record reasoning | Memo or annotation |
| Connect a passage or object to another | See-also link or relationship |
| Group items temporarily | Static or dynamic set |

## Case Setup

1. Define the unit of analysis before creating cases.
2. Create a case classification for each distinct case type.
3. Define attributes and allowed values; include explicit unknown, not applicable, or not collected values where necessary.
4. Create cases with stable IDs.
5. Code each participant's or case's full contribution to the matching case when case-based queries require it.
6. Assign attributes once through the classification structure.
7. Audit that no text is assigned to the wrong case.

For focus groups, distinguish participant cases from group-level file classifications. Preserve speaker identity and group context.

## Coding Workflow

- import or create the method-specific codebook;
- code deductively, inductively, or iteratively according to the declared analysis;
- use annotations for local comments and memos for sustained analytic reasoning;
- inspect coding stripes or highlighting as an audit aid;
- merge, split, rename, or uncode only with a decision record;
- check aggregation settings before interpreting a parent-code retrieval;
- export code definitions and revisions regularly.

## Relationships and Links

Create a relationship only when its type and direction have analytic meaning. Record evidence and reasoning in a linked memo. Use a see-also link for navigation when no substantive relationship is claimed.
