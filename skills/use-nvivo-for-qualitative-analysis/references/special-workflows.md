# Special NVivo Workflows

## Focus Groups

- format consistent speaker names;
- create participant cases when individual trajectories or attributes matter;
- classify each group file by design category, mode, site, moderator, and date;
- code substantive content and interaction separately when the analysis requires both;
- use matrices to compare themes or interaction patterns across group categories;
- keep field notes and debriefs linked but analytically distinct.

## Multimedia

- retain original media and document derivatives;
- synchronize transcript and media when possible;
- code image regions or audio/video time spans at the required granularity;
- record what is visible, audible, inferred, and contextual in separate notes;
- check whether export preserves timestamps and region references.

## Social Media and Web Data

- document collection date, platform, query, scope, and missing context;
- verify current import or capture support because platform integrations change;
- address terms, consent expectations, usernames, quoted-text searchability, deletion, and reidentification;
- do not treat platform metrics as neutral context.

## Surveys and Mixed Methods

- import datasets with stable respondent IDs;
- define closed variables as attributes and open-ended responses as codable qualitative content;
- create cases from rows only after verifying IDs and duplicates;
- use matrices or crosstabs to integrate qualitative codes with selected quantitative attributes;
- keep the mixed-method inference explicit outside the software.

## Literature Review

- import bibliographic metadata from a reference manager when supported;
- separate publication attributes from analytic codes;
- code conceptual, methodological, empirical, and gap-related content;
- write article and synthesis memos;
- use queries, matrices, maps, and cluster views to support—never automate—the synthesis;
- preserve citation keys for export back into the writing workflow.
