# AI 輔助質性分析技能包

以生成式 AI（Claude）輔助訪談與焦點團體資料之結構式質性內容分析時，實際使用的方法指示（技能說明檔），以及技能與原書的對照。

- 內容是依方法學工具書整理的步驟、判準與檢核事項，**不含書的原文，也不含任何研究資料或受訪者資訊**。
- 工具書須自行由圖書館或購買取得，書目見 `0_準備清單與安裝說明.md`。

## 從這裡開始

請先讀 [`0_準備清單與安裝說明.md`](0_準備清單與安裝說明.md)：需要準備的東西、工具書清單、安裝方式與書的位置設定。

## 流程

依 Kuckartz 與 Rädiker（2023）結構式質性內容分析的七個階段依序進行，編碼分兩輪。AI 提出初步的整理與編碼，研究者保留每一個方法與詮釋上的決定。

| 階段 | 內容 |
|---|---|
| 0 逐字稿整理（另加） | 整合轉錄稿、對照錄音校對、加行號、去識別化 |
| 1 初步閱讀、備忘、個案摘要 | AI 整理個案摘要與閱讀提示單；研究者對照逐字稿閱讀並寫下想法，整理成備忘 |
| 2 發展主類別並試用 | 由理論文獻、研究問題與訪談大綱訂出主類別，用一部分資料試用 |
| 3 第一輪編碼 | 只用主類別編全部資料，片段切粗 |
| 4 歸納次類別 | 把同一個主類別的片段全部調出來，由資料歸納次類別 |
| 5 第二輪編碼 | 把已編的片段分到次類別 |
| 6 分析 | 類別的彙整、個案與組別的比較、找反例 |
| 7 撰寫、記錄與揭露 | 撰寫結果、核對數字與引文、說明 AI 的使用 |

階段 1 到 7 是書上的七個階段。階段 0 與以其他 AI 工具檢視編碼是另加的步驟。細節見 `skills/ai-assisted-qualitative-content-analysis/SKILL.md`。

## 使用時請留意

- 技能是依書整理的規範，不是書本身；引用時請回到原書確認頁碼。
- 把逐字稿或錄音交給雲端 AI 服務前，請先確認倫理審查核准的資料處理方式。
- AI 輔助檢視不是獨立的人類第二編碼者，不宜報告為編碼者間一致性。
