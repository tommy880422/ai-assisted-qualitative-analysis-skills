# AI 輔助質性分析技能包

以生成式 AI（Claude）輔助訪談與焦點團體資料之結構式質性內容分析時，實際使用的方法指示（技能說明檔）、供查核的說明文件，以及 AI 使用揭露的附錄草稿。

- 內容是依方法學工具書整理的步驟、判準與檢核事項，**不含書的原文，也不含任何研究資料或受訪者資訊**。
- 工具書須自行由圖書館或購買取得，書目見 `0_準備清單與安裝說明.md`。

## 從這裡開始

請先讀 [`0_準備清單與安裝說明.md`](0_準備清單與安裝說明.md)：需要準備的東西、工具書清單、安裝方式與書的位置設定。

## 目前的狀態（2026-11-28）

- 總流程技能已改寫：依 Kuckartz 與 Rädiker（2023）結構式質性內容分析的七個階段依序進行，編碼分兩輪（第一輪只用主類別，第一輪編完才歸納次類別）。先前的版本把兩輪合為一輪，已不採用。
- 研究者正依新版流程重新分析，目前進行到階段 1（初步閱讀、備忘、個案摘要）。技能中階段 0 到 2 的做法已實際用過；階段 3 以後是依書上的程序寫成，還沒有實際跑過，跑過後會再修訂。
- 其餘四份技能中，`do-qualitative-content-analysis` 已逐條對照原書修改；另外三份尚未對照。

## 使用時請留意

- 技能是依書整理的規範，不是書本身；引用時請回到原書確認頁碼。
- 把逐字稿或錄音交給雲端 AI 服務前，請先確認倫理審查核准的資料處理方式。
- AI 輔助檢視不是獨立的人類第二編碼者，不宜報告為編碼者間一致性。
