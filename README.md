# AI 輔助質性分析技能包

以生成式 AI（Claude）輔助訪談與焦點團體資料之結構式質性內容分析時，實際使用的方法指示（技能說明檔），以及 AI 使用揭露的附錄草稿。

- 內容是依方法學工具書整理的步驟、判準與檢核事項，**不含書的原文，也不含任何研究資料或受訪者資訊**。
- 工具書須自行由圖書館或購買取得，書目見 `0_準備清單與安裝說明.md`。

## 從這裡開始

請先讀 [`0_準備清單與安裝說明.md`](0_準備清單與安裝說明.md)：需要準備的東西、工具書清單、安裝方式與書的位置設定。

## 內容

| 位置 | 說明 |
|---|---|
| `*.zip` | 五份可直接安裝的技能檔 |
| `skills/` | 五份技能的原始內容，可在 GitHub 上直接閱讀 |
| `disclosure/` | 生成式 AI 於資料分析之使用說明（附錄草稿，尚有待研究者確認的事項） |

| 技能 | 用途 |
|---|---|
| `ai-assisted-qualitative-content-analysis` | 總流程：AI 與研究者的分工、各階段可複製的指令、編碼手冊格式、揭露範本 |
| `do-qualitative-content-analysis` | Kuckartz 與 Rädiker 的質性內容分析 |
| `analyze-focus-group-data` | 焦點團體資料的分析 |
| `apply-jobs-to-be-done-theory` | 用途理論（Jobs to Be Done）的構念、設計、分析與撰寫 |
| `use-nvivo-for-qualitative-analysis` | 把分析設計落實到 NVivo |

## 使用時請留意

- 技能是依書整理的規範，不是書本身；引用時請回到原書確認頁碼。
- 把逐字稿或錄音交給雲端 AI 服務前，請先確認倫理審查核准的資料處理方式。
- AI 輔助檢視不是獨立的人類第二編碼者，不宜報告為編碼者間一致性。
